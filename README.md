# Python Manual Tool 🐍

A beginner-friendly interactive Python learning tool that covers 12 essential topics with clean syntax examples, code snippets, and an interactive menu. Perfect for beginners learning Python fundamentals right from the terminal.

## Features ✨

- 📋 **Interactive Menu** - Easy numbered navigation between all topics
- 📚 **12 Essential Topics** - Core Python basics covered in one place
- 💻 **Code Snippets** - Ready-to-understand syntax examples for each topic
- 📖 **Built-in Instruction Manual** - Press 14 to learn how to use the tool
- 📺 **All Topics Display** - Press 13 to view all 12 topics at once
- 🔁 **Loop Based Navigation** - Explore multiple topics without restarting
- ⏱️ **Smooth Experience** - Time-delayed output for better readability
- 🛡️ **Error Handling** - Invalid inputs are handled gracefully
- 🧹 **Clean & Readable** - Simple format designed for quick learning

## Topics Covered 📊

### Topic 1 — Print & Comments
- `print()` function usage
- Single-line comments with `#`
- Displaying text on screen

### Topic 2 — Variables
- Storing text, numbers, decimals
- Boolean values (True/False)
- Variable naming and assignment

### Topic 3 — Input
- Taking user input with `input()`
- Storing input in variables
- Displaying input back to user

### Topic 4 — Numbers & Math
- Addition, subtraction, multiplication
- Division and remainder operations
- Working with numeric variables

### Topic 5 — Conditions
- `if` and `else` statements
- Comparison operators (`>=`, `<=`, `==`)
- Decision making in Python

### Topic 6 — Loops
- `for` loop with `range()`
- `while` loop with counter
- Loop control and iteration

### Topic 7 — Lists
- Creating lists with multiple items
- Accessing items by index
- Adding items with `.append()`

### Topic 8 — Strings
- String creation and display
- Character indexing (`text[0]`)
- Finding string length with `len()`

### Topic 9 — Functions
- Defining functions with `def`
- Calling functions
- Grouping reusable code

### Topic 10 — Dictionaries
- Key-value pair storage
- Accessing values by key
- Dictionary syntax and structure

### Topic 11 — Files
- Writing to files with `open('w')`
- Reading from files with `open('r')`
- File close operations

### Topic 12 — Error Handling
- `try` and `except` blocks
- Handling `ValueError`
- Safe user input processing

### Extra Options

| # | Option | Description |
|---|--------|-------------|
| 13 | All Topics on Display | View all 12 topics at once |
| 14 | Instruction Manual | How to use this tool |
| 0 | Exit | Close the program |
